## 🚀 成果与实践

### 🌱 "蒲公英计划·感恩有你，砥砺前行" 主题网站（独立项目）

- **做了什么**：为学校"蒲公英计划"感恩主题教育制作的纯前端静态网站，1 个主页 + 3 个完整的人物故事详情页，约 170 KB 手写 HTML/CSS/JS
- **功能模块**：
  - **历史进程**：1949 建国 / 1978 改革开放 / 2012 新时代"站起来—富起来—强起来"三阶段时间线
  - **国家成就**：经济、科技、民生、国际影响力数据卡片（高铁 4 万公里、嫦娥五号、近一亿人脱贫等）
  - **感恩故事**：林占熺（菌草之父）、次仁曲宗（雪域教育）、申六兴（护林员）三位人物独立故事页，各含生平时间线、优秀品质画像、贡献影响数据三大板块
  - **互动参与**：电子签名墙（提交祝福语）、国家成就知识挑战（5 题计分问答）、历年 GDP 数据图表
- **技术要点**：多页面间跳转与统一导航结构、时间线/卡片等组件在四个页面中的复用、表单与答题逻辑的原生 JS 交互实现
- **收获**：第一次系统体会到"组件复用"和"页面信息架构"的价值——四个页面的时间线是同一套结构改数据，后期改样式一处生效；也踩过不少 CSS 盒模型和事件绑定的坑，全靠逐行对照 MDN 解决


### 🤖 HF Flux 真实感人像生图应用（本课程作业）

- **做了什么**：调用 Hugging Face 上的 `XLabs-AI/flux-RealismLora` 模型（FLUX.1-dev + 照片真实感 LoRA），做成一个可交互的网页生图工具
- **技术要点**：Flask 后端代理 Hugging Face Inference Providers API；令牌只存在于后端环境变量，浏览器不接触密钥；前端提交提示词/负向提示词/种子，后端返回 base64 图像；每次调用记录耗时与参数写入日志
- **踩过的坑**：网上 2024 年前的老教程用 `api-inference.huggingface.co`，现在那个接口已经停用，直接报 410——最后是靠读官方文档才搞明白要改用 `InferenceClient(provider=...)`
